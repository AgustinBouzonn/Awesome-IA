Stack tecnológico recomendado para desarrollo de Inteligencia Artificial, desde lo clásico hasta Generative AI.

## 🐍 Lenguajes y Entornos

*   **Python:** El lenguaje estándar de la industria para IA y Data Science. [Web](https://www.python.org/)
*   **Anaconda / Miniconda:** Gestión de entornos virtuales y paquetes. [Web](https://www.anaconda.com/)
*   **Jupyter Lab:** Entorno interactivo de desarrollo web, sucesor de Jupyter Notebooks. [Web](https://jupyter.org/)
*   **Google Colab:** Notebooks en la nube con acceso a GPU gratuita (T4) y TPU. Ideal para empezar. [Web](https://colab.research.google.com/)
*   **VS Code:** El editor de código más popular, con excelentes extensiones para Python, Jupyter y Copilot. [Web](https://code.visualstudio.com/)

## 🛠 Librerías Fundamentales (Python)

### Data Science & Análisis
*   **Pandas:** Manipulación y análisis de datos estructurados (DataFrames). [Web](https://pandas.pydata.org/)
*   **NumPy:** Computación numérica eficiente y manejo de matrices. [Web](https://numpy.org/)
*   **Matplotlib / Seaborn:** Visualización de datos estática. [Web](https://matplotlib.org/)
*   **Scikit-Learn:** La librería go-to para Machine Learning clásico (Regresión, Clasificación, Clustering, PCA). [Web](https://scikit-learn.org/)
### Deep Learning
*   **PyTorch:** Framework flexible y dinámico, favorito en investigación y cada vez más en producción. (Desarrollado por Meta). [Web](https://pytorch.org/)
*   **TensorFlow / Keras:** Framework robusto y escalable. (Desarrollado por Google). [Web](https://www.tensorflow.org/)
*   **Fastai:** Capa de alto nivel sobre PyTorch que simplifica drásticamente el entrenamiento de modelos SOTA. [Web](https://docs.fast.ai/)
### Generative AI & LLMs (Modern Stack)
*   **Hugging Face Transformers:** La librería más importante hoy en día. Acceso a miles de modelos pre-entrenados (BERT, Llama, Mistral, Whisper). [Web](https://huggingface.co/docs/transformers)
*   **LangChain:** Framework para construir aplicaciones que conectan LLMs con otras fuentes de cómputo o conocimiento. [Web](https://www.langchain.com/)
*   **LlamaIndex:** Framework especializado en conectar LLMs con tus datos privados (RAG - Retrieval Augmented Generation). [Web](https://www.llamaindex.ai/)
*   **Diffusers:** Librería para generación de imágenes y audio (Stable Diffusion, ControlNet). [Web](https://huggingface.co/docs/diffusers)
*   **Ollama:** Herramienta para correr LLMs open source (Llama, Mistral, Gemma y otros) localmente de forma muy sencilla. [Web](https://ollama.com/)

## ☁️ APIs y Servicios Cloud

### Modelos como Servicio (MaaS)
*   **OpenAI API:** Acceso a los modelos GPT, generación de imágenes y Whisper. [Web](https://platform.openai.com/docs)
*   **Anthropic API:** Acceso a la familia de modelos Claude, con foco en razonamiento, código y contextos largos. [Web](https://www.anthropic.com/api)
*   **Hugging Face Inference API:** Hosting de modelos open-source con API serverless o dedicada. [Web](https://huggingface.co/docs/inference-providers)
*   **Groq:** API de inferencia ultrarrápida (LPU) para modelos open source. [Web](https://groq.com/)
### Nubes Públicas (Enterprise)
*   **AWS SageMaker:** Suite completa de ML en Amazon Web Services. [Web](https://aws.amazon.com/sagemaker/)
*   **Google Cloud Vertex AI:** Plataforma unificada de IA de Google. [Web](https://cloud.google.com/vertex-ai)
*   **Azure AI Foundry** (ex Azure AI Studio): Plataforma de IA de Microsoft, incluye Azure OpenAI Service. [Web](https://ai.azure.com/)

## 🖥 Herramientas de Visualización y Web Apps

*   **Streamlit:** Permite crear web apps de data science interactivas usando solo Python. Muy usado para prototipos. [Web](https://streamlit.io/)
*   **Gradio:** Estándar para crear demos web rápidas para modelos de ML (muy integrado con Hugging Face). [Web](https://www.gradio.app/)
*   **Power BI / Tableau:** Herramientas líderes en Business Intelligence y Dashboards empresariales. [Power BI](https://www.microsoft.com/power-platform/products/power-bi) \| [Tableau](https://www.tableau.com/)
