## 🌍 Cursos Online (Global)

Recursos gratuitos o de bajo costo reconocidos mundialmente.

### Aprendizaje Automático y Deep Learning
*   **Coursera:** [Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) - Ideal para empezar con las bases.
*   **Fast.ai:** [Practical Deep Learning for Coders](https://course.fast.ai/) - Enfoque "top-down" para aprender haciendo. Muy recomendado.
*   **Hugging Face:** [The Hugging Face Course](https://huggingface.co/course/chapter1/1) - La referencia para NLP (Procesamiento de Lenguaje Natural) y Transformers.
*   **Kaggle Learn:** [Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning) - Tutoriales interactivos y rápidos.

### Matemáticas y Estadística
*   **Khan Academy:** [Estadística y Probabilidad](https://es.khanacademy.org/math/statistics-probability)
*   **3Blue1Brown:** [Neural Networks (Youtube)](https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi) - Las mejores explicaciones visuales sobre cómo funcionan las redes neuronales.

## 📚 Libros Recomendados

### Introductorios (Teoría + Práctica)
*   **An Introduction to Statistical Learning** (James, Witten, Hastie, Tibshirani) - [Descarga Gratuita](https://www.statlearning.com/) - El mejor punto de partida teórico/práctico.
*   **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow** (Aurélien Géron) - [O'Reilly](https://www.oreilly.com/library/view/hands-on-machine-learning/9781492032632/) - Indispensable para implementación.

### Deep Learning
*   **Deep Learning** (Ian Goodfellow et al.) - [Lectura Online](http://www.deeplearningbook.org/) - La referencia teórica académica.
*   **Deep Learning for Coders with fastai and PyTorch** (Jeremy Howard & Sylvain Gugger) - [Amazon](https://www.amazon.com/Deep-Learning-Coders-fastai-PyTorch/dp/1492045527)

### Otros
*   **Pattern Recognition and Machine Learning** (Christopher Bishop) - [Descarga Gratuita (Microsoft)](https://www.microsoft.com/en-us/research/uploads/prod/2006/01/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf)
