## Contribuir

Las contribuciones son bienvenidas: una carrera nueva, un dataset público argentino, una comunidad activa o un enlace que dejó de funcionar.

- Leé la [guía de contribución](CONTRIBUTING.md) antes de abrir un Pull Request.
- Para sugerir algo sin editar archivos, abrí un [issue](https://github.com/AgustinBouzonn/Awesome-IA/issues).
- Al participar aceptás el [Código de Conducta](CODE_OF_CONDUCT.md).

Los próximos pasos del proyecto están en el [Roadmap](ROADMAP.md).
